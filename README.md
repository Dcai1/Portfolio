# Portfolio Website

This is my personal portfolio website, built with Next.js and Tailwind CSS.
It showcases my projects, skills, and experience as a full-stack developer.

# Tech Stack

1. Next.js
2. React
3. Tailwind CSS
4. Framer Motion
5. TypeScript
6. _~~Three.js~~_ (not yet implemented, but soon!)

# Features

1. Responsive design (very mobile-friendly)
2. Animations with Framer Motion
3. Contact information & links
4. My projects and a brief description about them, including their tech stack
5. About page

# Future Goals

1. Incorporate three.js for a more-intuitive experience
2. Add more details onto the portfolio page, such as GitHub stats, and more social links
3. Let's not get too far ahead, I'm still learning!

# Why I Built This?

As you _may_ have noticed, I'm not the best when it comes to designing websites from scratch. I'm better when it comes to coding the backend. But this didn't stop me. I never back down from challenges, and I'm always looking for ways to improve my skills.

As a web developer, I could leave an impression by showcasing all my projects and skills on a website I built from the ground up, all alone, including all frontend assets. Creating this portfolio involved planning the structure, designing graphical elements using tools like Canva and Figma, and making sure my design still aligned with website colors. I also focused on designing a clean and responsive layout, and ensuring smooth responsiveness across all types of devices.

Along the way, I applied technical skills such as React, Next.js, Tailwind CSS, and soft skills like problem-solving, adaptability, and attention to detail.

This was a fun and rewarding journey that also challenged me to think and act like both a developer and a UI designer.
Even now, I’m always looking for ways to expand this project with new pages, features, or details as I continue to grow my skill set.
